# Music Library Frontend

Современный фронтенд для музыкальной библиотеки, построенный на React + TypeScript + Vite.

## Требования

- **Node.js** версии 18.0.0 или выше
- **npm** версии 8.0.0 или выше

### Проверка версии Node.js

```bash
node --version
```

Если версия ниже 18, необходимо обновить Node.js.

### Обновление Node.js

#### Используя nvm (рекомендуется):

```bash
# Установка nvm (если еще не установлен)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash

# Перезагрузите терминал или выполните:
source ~/.bashrc

# Установка Node.js 18
nvm install 18
nvm use 18
nvm alias default 18
```

#### Или скачайте с официального сайта:
https://nodejs.org/

## Технологии

- **React 18** - UI библиотека
- **TypeScript** - типизация
- **Vite** - сборщик и dev-сервер
- **React Router** - маршрутизация
- **React Query** - управление состоянием и кэширование
- **React Hook Form** - работа с формами
- **Tailwind CSS** - стилизация
- **Axios** - HTTP клиент
- **Lucide React** - иконки

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev
```

Приложение будет доступно по адресу http://localhost:3000

## Сборка

```bash
npm run build
```

## Функционал

### Аутентификация
- Регистрация пользователя
- Вход в систему
- Верификация email

### Поиск
- Поиск по артистам, альбомам и песням
- Фильтрация по типам
- Пагинация результатов

### Управление контентом (требует авторизации)
- Создание артистов
- Создание альбомов
- Добавление песен с текстами
- Управление профилем

### Просмотр
- Детальная информация об артистах
- Просмотр альбомов и песен
- Отображение текстов песен

## Структура проекта

```
src/
├── api/          # API клиенты
├── components/   # Переиспользуемые компоненты
├── contexts/     # React контексты
├── pages/        # Страницы приложения
├── types/        # TypeScript типы
└── utils/        # Утилиты
```

## Переменные окружения

Создайте файл `.env`:

```
VITE_API_URL=http://localhost:8081/api/v1
```
